### Armando Monteiro

Full Stack Developer from Brazil, working where web engineering, LLMs and technical SEO meet.

Currently the only developer at a performance marketing agency, which means I own the architecture, the infrastructure and the deploy pipeline.

**What I build at work**

- **LLM agents with tool calling** that investigate why a client's organic traffic went up or down, instead of someone writing that analysis from scratch every month.
- **A design-to-page generator**: reads the layout from the Figma REST API and emits page builder components, validated against the platform's own schema. About 8 hours per page down to 2.
- **The infrastructure it all runs on**: Cloud Run, Cloud SQL, Secret Manager and CI/CD on Google Cloud, deployed by approving a pull request.

**What I'm learning now**

Retrieval with evaluation, on my own notes. A hybrid search (lexical + local embeddings via Ollama, fused with RRF), measured against a hand-written question set: recall@5 went from 79% to 90%. The rule I follow: nothing ships unless it beats the baseline.
